    What it does

    Answers, not just bars.

    A disk map tells you something is big. Strata tells you what it is, which app made it, and whether removing it is safe.

    • MFT scanning

      Reads $MFT directly instead of walking folders, with exact sizes for hardlinks, streams, compression and cloud files.

    • Live updates

      Tails the USN change journal and patches the index in place, so every view stays current without a rescan.

    • Explains every file

      Rule packs name the category, owning app and safety tier for each path, and show exactly which rule matched.

    • Safe cleanup

      A hard-coded never-delete list, re-verification right before every delete, Recycle Bin by default and one-click restore.

    • Instant search

      Name search with filters like *.gguf size:>1gb. First results in about a millisecond over 5 million names.

    • History & duplicates

      Snapshots show what grew since the last scan. The duplicate finder skips hardlinks and never downloads cloud-only files.

    Architecture

    The UI never runs elevated.

    Privileged work happens in a small helper behind a locked-down named pipe. Without it, a standard scanner feeds the same index.

    How a delete happens

    1. 01Never-listHard-coded system paths are refused, whatever the rules say.
    2. 02Re-verify by file idRight before acting, the volume serial and 128-bit file id must still match.
    3. 03Recycle BinDeletes go to the Recycle Bin by default, with the undo log written first.
    4. 04RestoreOne click puts it back, and a restore never overwrites.

    No telemetry. Everything stays on your machine. Scans, history, settings and the undo log stay local, and file names never leave it. The only network request is the update check.
