01What it does

Answers, not just bars.

A disk map tells you something is big. Strata tells you what it is, which app made it, and whether removing it is safe.

  • MFT scanning

    Reads $MFT directly instead of walking folders, with exact sizes for hardlinks, streams, compression, sparse files and cloud placeholders.

    How it scans

  • Live index

    Tails the USN change journal and patches the index in place, so every view stays current without a rescan.

    Live updates

  • Explains every file

    {{rules.count}} built-in rules name the category, owning app and safety tier for each path, and show which rule matched.

    Rule packs

  • Safe cleanup

    A never-delete list in code, re-verification by file id right before acting, Recycle Bin by default and one-click restore.

    Deletion safety

  • Instant search

    Name search with filters like *.gguf size:>1gb. First results in {{bench.search}} over 5 million names.

    Query syntax

  • History & duplicates

    Snapshots show what grew since the last scan. The duplicate finder skips hardlinks and never downloads cloud-only files.

    History and duplicates

  • Activity

    Opt-in ETW tracing shows which program is writing what, aggregated per folder and per hour.

    Activity tracking

  • Five ways to see a drive

    Treemap, sunburst, icicle, circle packing and mind map, laid out in Rust and drawn with WebGL2 at a steady frame rate.

    Views

03Architecture

The UI never runs elevated.

How a delete happens

  1. 01Never-listHard-coded system paths are refused, whatever the rules say.
  2. 02Re-verify by file idRight before acting, the volume serial and 128-bit file id must still match.
  3. 03Recycle BinDeletes go to the Recycle Bin by default, with the undo log written first.
  4. 04RestoreOne click puts it back, and a restore never overwrites.
