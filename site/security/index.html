Security & privacy

Small privileged surface. Nothing leaves your PC.

A disk tool needs deep access to your drives. Strata keeps that access in one small, verified process, checks every delete several times over, and sends nothing about your files anywhere.

01Process model

The window never runs as administrator.

An elevated web runtime would widen the attack surface and break drag-and-drop from Explorer. So the app stays unelevated, and only the work that truly needs administrator rights runs in a separate helper.

The helper trusts nothing it is told

The pipe proves who is talking; the helper still validates what is asked. A delete is accepted only as a volume, file id, expected path, expected size and expected modification time, and is checked again against the helper’s own copy of the never-delete list.

Least privilege, even when elevated

At start the helper drops every privilege except the three it needs, and enables backup and volume rights only while a volume is being opened. Deletes run with ordinary administrator access checks, so a file that denies administrators stays undeletable.

Declining is always safe

If you say no to the UAC prompt, Strata uses its standard scanner. Optional service mode serves only the configured app image run by a local administrator, and stops after 5 idle minutes.

02Helper pipe

A pipe only you can open, to a helper that proves who it is.

Before either side parses a single byte, each checks the other’s identity with the kernel and with Windows code signing. Then they agree on a protocol version, or hang up.

  1. Name

    Random per launch: your user SID plus 128 bits from BCryptGenRandom, passed on the helper’s command line.

  2. Creation

    First-instance only, so a squatted name fails; remote clients rejected; one instance per pipe.

  3. DACL

    You get read and write only, with no create-instance or permission changes; SYSTEM gets full access; owner rights are limited to reading the descriptor.

  4. Integrity

    An explicit medium label with no-write-up: the app can connect, low-integrity and AppContainer processes cannot.

  5. Peer check

    Client process id from the kernel, then image path, start time and Authenticode signer, which must match the helper’s own. The app verifies the helper the same way.

  6. Framing

    Every message is one length-prefixed frame capped at 64 MiB; the length is checked before anything is allocated, and any framing error closes the connection.

  7. Rate limit

    A token bucket per connection: bursts of 200, 100 requests a second sustained.

03Before every delete

Seven checks, any of which can say no.

Deletion is the only destructive operation in Strata, and every layer fails closed: when a check cannot prove an item is the one you confirmed, the item is left alone.

  1. 01

    Never-delete list

    In code and independent of rule packs: volume roots, the Windows folder, Program Files and WindowsApps, every profile root, known-folder roots, boot, paging and hibernation files, NTFS metadata and Strata itself. Enforced by the app and again by the helper.

  2. 02

    Every spelling

    \\?\, \??\, UNC and administrative shares, volume GUID and device paths with every mount point, trailing dots and spaces, and 8.3 short names.

  3. 03

    Handle checks

    Opened without following reparse points, its resolved path checked again, and its volume serial, file id, size and modification time matched against the scan.

  4. 04

    Recycle Bin

    Moved through the Shell with every ancestor held open, so none can be swapped for a junction mid-operation. Anything the Shell would delete permanently is aborted.

  5. 05

    Pre-flight

    Items that can’t be recycled (no Recycle Bin, too large, path too long) are listed before anything happens, and need a separate permanent-delete confirmation.

  6. 06

    Locks

    Restart Manager names the program holding a file. Closing it is a polite request after you agree, never a kill.

  7. 07

    Write-ahead log

    A record is committed before each item is touched and completed after. If Strata stops mid-way, the next launch marks the entry as interrupted.

04Updates and downloads

Signed updates. Checkable downloads.

Installed copies only install updates signed with the project’s release key, and every installer you download by hand comes with a published SHA-256 checksum.

Signed update manifests

The app reads a small manifest, latest.json, from GitHub Releases. Each installer it lists carries a signature, and the app checks it against the public key built into Strata before installing. An update that fails to verify is never run.

If a just-installed update fails to start, Strata offers to reinstall the previous version, which is verified the same way.

SHA-256 checksums

Every release publishes SHA256SUMS.txt beside its installers; the releases page and the download section show them with a copy button. To check a download in PowerShell:

Get-FileHash .\Strata_{{version}}_x64-setup.exe -Algorithm SHA256

The installers aren’t code-signed yet, so Windows SmartScreen may ask you to confirm (More info → Run anyway).
